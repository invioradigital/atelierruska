# Atelier Ruska — Prototype de site vitrine

Site statique (HTML/CSS/JS) responsive, créé pour une première présentation client.

## Lancer en local
Ouvrez `index.html` dans votre navigateur. Pas d'installation nécessaire.

## Publier sur GitHub Pages
1. Créez un repository public (ex. `atelier-ruska-demo`).
2. Importez `index.html` et le dossier `assets/` à la racine (pas seulement le ZIP).
3. `Settings` → `Pages` → `Deploy from a branch` → `main` → `/ (root)` → `Save`.
4. Le lien sera du type `https://VOTRE-NOM.github.io/atelier-ruska-demo/`.
